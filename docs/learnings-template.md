# Learnings · [project name]

Working memory for this project, one section per role. It gets filled at each phase's retro,
using the same entry format as web-lab's own `learnings/<role>.md` files so it merges without
reinterpretation later. Never store secrets, third parties' personal data, or client content
here beyond the lesson itself. web-lab's Web Master harvests this file read-only
(`/web-master harvest`), or the user hands it to a web-lab session running that command, and each
section's entries get appended into the matching `learnings/<role>.md` there, with date and
project preserved. Requests to change a role, skill or template go here as "Proposed adjustment"
lines; nobody edits web-lab from a project.

## Entry format

```
## yyyy-mm-dd · <project> · phase N
- Worked: ...
- Did not work: ...
- Preference: ... (candidate for PREFERENCES.md)
- Proposed adjustment: to the role / to the skill / to template X
```
